## Возможности

- **Произвольные пары клавиш** — добавляйте любое количество пар для ремаппинга, не ограничиваясь стандартными WASD.
- **Исключения по процессам** — указывайте приложения, для которых SnapKeySharp не будет активен. Полезно для чатов, IDE и других программ, где перехват не нужен.
- **Алгоритм last-input-wins** — при одновременном нажатии двух клавиш из пары приоритет отдаётся последней нажатой.
- **Встроенный лаунчер** — отдельное приложение для установки, обновления, починки и удаления SnapKeySharp.
- **Автообновление** — при запуске приложение проверяет наличие новой версии через GitHub Releases + зеркало (Pastebin + Dropbox) и предлагает обновиться.
- **Автозапуск с Windows** — SnapKeySharp стартует вместе с системой и работает в фоне.
- **Иконка в трее** — быстрый доступ к настройкам и выходу через контекстное меню в системном трее.
- **Современный UI** — интерфейс на WPF с использованием библиотеки ModernWpfUI.

## Как это работает

1. **Глобальный перехват** — через низкоуровневую клавиатурную хуку `WH_KEYBOARD_LL` приложение перехватывает каждое нажатие клавиши в системе.
2. **Проверка активного окна** — движок определяет foreground-процесс и сверяет его с JSON-списком исключений. Если процесс в списке — клавиша пропускается без изменений.
3. **SOCD-разрешение** — если нажаты две клавиши из одной пары, старой отправляется синтетический `KeyUp` через `SendInput` со специальным флагом, чтобы избежать рекурсии.
4. **Самоблокировка** — приложение корректно обрабатывает собственный ввод, исключая эффект "удвоения" символов при наборе текста в интерфейсе.

## Установка

### Быстрый старт (рекомендуется)

1. Перейдите в раздел [Releases](https://github.com/cerule-ui/SnapKeySharp/releases/latest) и скачайте `SnapKeySetup.zip`.
2. Распакуйте архив в любую папку.
3. Запустите `SnapKeyLauncher.exe` и нажмите **Install**.
4. После установки исходную папку можно удалить — лаунчер доступен через **Панель управления → Программы и компоненты → SnapKey**.

### Сборка из исходников

```bash
# Клонирование репозитория
git clone https://github.com/cerule-ui/SnapKeySharp.git
cd SnapKeySharp

# Сборка решения
dotnet build SnapKeySharp.slnx

# Запуск
SnapKeySharp\bin\Debug\net10.0-windows\SnapKeySharp.exe
SnapKeyLauncher\bin\Debug\net10.0-windows\SnapKeyLauncher.exe
```

**Требования:**
- Windows 10/11 (x64)
- .NET 10.0 SDK
- Visual Studio 2022 или Rider / VS Code с C# Dev Kit

## Обновления

SnapKeySharp использует двухуровневую систему проверки обновлений:

1. **GitHub Releases** — основной источник. Приложение сверяет текущую версию с последним релизом.
2. **Pastebin + Dropbox** — резервное зеркало. В Pastebin хранится JSON с метаданными (`version`, `changelog`, `download_url`), а архив с программой размещается на Dropbox (ссылка с `dl=1` для прямого скачивания).

При обнаружении новой версии приложение предлагает пользователю обновиться. Процесс обновления: закрытие всех процессов SnapKeySharp → замена файлов → перезапуск.
