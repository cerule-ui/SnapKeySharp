------- English -------

SnapKeySharp is finally here!

Fully written in WPF & C#.
Also used: ModernWPFUI (0.9.6) & Hardcodet.NotifyIcon.Wpf (2.0.1)

Installation:
1. Download [SnapKeySetup.zip](https://github.com/cerule-ui/SnapKeySharp/releases/latest/download/SnapKeySetup.zip)
2. Unzip it anywhere (you'll delete it anyway)
3. Run SnapKeyLauncher.exe and choose Install
4. Then you can delete folder, created on step 2

**To open the launcher, go to Control Panel -> Uninstall a program -> SnapKey -> Uninstall**

Enjoy! Fully made by cerule.

------- Русский -------

SnapKeySharp наконец-то здесь!

Полностью написан на WPF & C#.
Также использовались библиотеки: ModernWPFUI (0.9.6) & Hardcodet.NotifyIcon.Wpf (2.0.1)

Установка:
1. Скачайте [SnapKeySetup.zip](https://github.com/cerule-ui/SnapKeySharp/releases/latest/download/SnapKeySetup.zip)

3. Запустите SnapKeyLauncher.exe и выберите Install
4. После установки можно удалить папку, созданную на шаге 2

**Чтобы попасть в лаунчер, вам необходимо зайти в панель управления -> удаление программ -> SnapKey -> Удалить**
